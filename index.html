问道（wendao）· main 治理工作树

这是 kuight/wendao 仓库的根入口页。当前 main 分支是一个「源码 + 文档 + 历史归档」的治理工作树，并非单一可运行版本包。

这是什么

  • 面向福建高中生的「修仙叙事 + 学科刷题 + 离线单机」学习游戏仓库
  • 纯前端：HTML + CSS + Vanilla JS，无后端、无数据库，localStorage 本地存档
  • 六科：物理 / 化学 / 地理 / 数学 / 语文 / 英语

如何运行

选择 archive/备份/ 中的完整版本包解压后直接打开 index.html，或在目录下执行：

python3 -m http.server 8000

版本真相（重要）

不要仅凭版本号判断先后。 详见 docs/VERSION_TRUTH.md。例如 v4.3.5f 的实际完成时间晚于 v4.3.6-final；v2.2 实测早于 v3.0；原档合并 与 学习游戏记忆_root 内容完全同源（Jaccard=1.0000）。
