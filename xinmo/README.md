# 错题心魔（xinmo）

一个只在本机运行的错题复习工具：每天把错题收进来，按遗忘曲线安排重做，一眼看到积累在变多。

它不是题库、不教课、不判分。判题和讲解由你自己或外部 AI 完成，它只负责记录和安排复习。

## 它帮你做什么

- **录入错题**：选学科 → 点知识点 → 写一句"考什么、为什么错" → 可选拍/粘贴题目图 → 入库。一道题 20 秒内录完。
- **每天重做**：首页告诉你今天该重做哪几道。重做时先自己答，再对答案判定（选错自动排回当天，做对进入下一轮）。
- **看到积累**：足迹页有知识树（哪些知识点遇过、在复习、已炼化）和 90 天热力图，晚上看一眼就知道今天干了什么。

## 一键启动（Windows）

### 1. 装依赖（只需一次）

需要 Python 3.10+。打开命令行（cmd 或 PowerShell）：

```
pip install fastapi uvicorn pillow
```

### 2. 启动

把整个 xinmo 文件夹放到你想放的地方（例如 `D:\xinmo`），然后进入该文件夹：

```
cd D:\xinmo
python -m uvicorn server:app --port 8092
```

看到 `Uvicorn running on http://127.0.0.1:8092` 就成功了。

### 3. 打开

浏览器打开：`http://127.0.0.1:8092`

### 4. 录一道题试试

1. 点顶部"录入"标签。
2. 选学科（物理/化学/地理/语文/数学/英语）。
3. 点章节展开，再点一个知识点（比如"牛顿第二定律"）。
4. 在"这题考什么"框里写一句话（比如"合外力与加速度方向搞反了"）。
5. 有题目照片就 Ctrl+V 粘贴或拖进去（可选）。
6. 点"入库"。
7. 切到"今日"标签，会看到这道题出现在今天清单里。

## 每天都做什么

- 打开首页，看今天该重做哪几道。
- 每道题：先自己写出答案 → 点提交 → 系统判定 → 对答案 → 选"顺畅做对"或"卡了一下"。答错了会自动排回今天，趁热再做一遍。
- 全部做完显示"今日已清心"。

## 每周备份（重要，唯一防丢措施）

你的数据存在本机的 `data/xinmo.db` 里，图片在 `data/images/`。**硬盘坏了就全没了**。

每周点一次：浏览器打开 `http://127.0.0.1:8092/api/backup`，会下载一个 zip。把它存到网盘或 U 盘。这是唯一的防丢手段，请养成习惯。

## 常见问题

- **端口被占用**：换一个端口，如 `python -m uvicorn server:app --port 8093`，浏览器打开对应端口。
- **图片没显示**：确认提交时图片粘贴/上传成功，图片存在 `data/images/` 下。
- **LLM 判表达式**：目前表达式/公式题判定已降级为手动自评（未配置 LLM）。等你真正需要了，在 `config.local.json` 里填上 `text` 通道的 `base_url`/`api_key`/`model` 即可开启自动判等价。

## 给想改代码的人

代码结构：`server.py`(后端) / `schedule.py`(复习调度算法) / `judge.py`(判定逻辑) / `web/`(前端，纯原生 JS 无框架，中文文案在 `web/i18n.json`) / `data/topics.json`(知识点库)。改完代码后，重启服务即可生效。
