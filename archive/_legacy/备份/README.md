# archive/备份/

历史归档目录。已不再主版本使用的文件都放到这里。

## 应该放什么

- `wendao-v4.3.5j.zip`、`wendao-v4.3.6a.zip`、`wendao-v4.3.7.zip`：完整历史版本压缩包
- `问道修仙学院-v2.2-phase1-bugfix.zip`：修真 v2.2 早期版本
- `杂项分支.zip`：零碎分支合集
- `部分历史文件.zip`：原仓库根目录带过来的零散历史包
- `*bank-v436-*.js` / `*bank-v437-*.js` / `*bank-v438-*.js`：题库所有历史快照
- `sound-effects-v437.js` / `subject-bg-v437.css`：音效、样式历史快照
- `battle-arena-v437-balance.js` / `reclassify-bank-v437a.js` / `v437a-loader.js` / `v437a-quality-fix.js`：v4.3.7 系列开发中间产物

## 不放什么

- 当前在用的源文件（请放 `src/项目/`）
- 预览 HTML（请放 `src/preview/`）

## 现有根目录文件迁移提示

仓库根目录现存的 `学习游戏记忆.z01` 与 `学习游戏记忆.zip`（分卷压缩包）建议合并解压后改名为 `wendao-game-memories-combined.zip` 后移到本目录。
