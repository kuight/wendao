## 一、题库大清洗（自动脚本 + 人工规则）

用自动化脚本剔除了主题库里所有模板参数化生成的水题，识别规则：

- ✗ **模板题干**：`综合题（第X题）` / `见教材例题` / `「XX」的核心公式或性质是` / `分析XX时首先要考虑的因素是` / `下列判断XX的方法中正确的` / `=高能电磁波（请判断）` 等
- ✗ **无营养解析**：`见解析` / `见教材` / `建议默写十遍` / `A项是标准方法` / `判断XX要看关键特征` 等
- ✗ **水选项**：`凭感觉` / `完全无关的现象` / `没差异` / `没实际应用` / `随机` / `只有理论意义` 等
- ✗ **超短判断题**：题干含`（请判断）`但解析等于题干本身
- ✗ **模板填空**：answer 是 `见解析`、`见教材`、`同上`
