## 🎨 四、语文特色内容（老师原文之外，我按考纲补的）

**每篇都有的三大附加值：**

1. **字音字形警示**：破音字（渐 jiān 非 jiàn）、生僻字（徂 cú、阰 pí、搴 qiān、霁 jì）
2. **古今异义标注**：贿=财物（非贿赂）、自由=自作主张、可怜=可爱、教训=教养、交通=交错相通、爽=差错
3. **典故网络打通**：
   - 《扬州慢》标出化用杜牧的 4 处诗典（春风十里 / 豆蔻 / 青楼梦 / 二十四桥）
   - 《蜀相》"映阶碧草自春色" ↔《扬州慢》"废池乔木""波心荡冷月无声" 物是人非同款手法
   - 《氓》比兴 ↔《离骚》香草美人 两大源头对照
   - 《孔雀东南飞》"相"字五义（代我/代你/代她/相貌/互相）系统整理

## 🔧 七、开发中修复的 bug

**Bug 1：兜底 fallback 抢先挂载导致手写讲义无法覆盖**
- 症状：v438 Loader 先给 chn_xbx_* 挂了 fallback，v439 patch 检查 `m.deepDive` 已存在就跳过了，结果手写讲义没生效
- 修复：patchLoader 在扫描时先 `m.deepDive = null` 清掉 fallback，再让手写强制覆盖
- 位置：`assets/learning-modes-chinese-patch-v439.js` 第 ~110 行
