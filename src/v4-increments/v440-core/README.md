# v440-core/

wendao4.4.0 核心增量：化学 12 篇手写讲义/秘籍 + 雷劫限时闯关。
源：`wendao4.4.0.zip` → `wendao/assets` + `wendao/data`。
包含 4 个文件：

| 文件 | 内容 |
|---|---|
| thunder-tribulation-v440.js | 雷劫主引擎 (含 3 档模式) |
| learning-modes-chemistry-patch-v440.js | 化学学习模式 patch |
| chemistry-xbx-manual-v440.js | 12 篇**合一**手写秘籍 |
| deep-dive-chemistry-v440.js | 12 篇**合一**手写讲义 |

**注意**：化学 12 篇 (`chem_xbx_lizi`、`chem_xbx_redox`、`chem_xbx_stranger`、`chem_xbx_amount`、`chem_xbx_thermogravimetric`、`chem_xbx_sodium`、`chem_xbx_iron`、`chem_xbx_aluminum`、`chem_xbx_chlorine`、`chem_xbx_sulfur`、`chem_xbx_nitrogen`、`chem_xbx_silicon`) 作为 `CHEMISTRY_MANUALS` 数组元素挂在 `chemistry-xbx-manual-v440.js` 里，**不是 12 个独立 .js 文件**。
