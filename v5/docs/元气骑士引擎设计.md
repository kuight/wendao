## 1. 摄像机系统

### Soul Knight 的摄像机行为（观察结论）
- 摄像机**跟随玩家**，但有**死区（dead zone）**——玩家在死区内小幅移动时摄像机不跟
- 玩家碰到死区边缘时，摄像机**平滑追赶**（easing/lerp，不是瞬切）
- 摄像机**限定在当前房间范围内**，不会显示隔壁房间
- 切换房间时，摄像机**平滑过渡**到新房间中心（~0.3 秒缓动）

### 实现方案
```
camera = {
  x, y,          // 当前摄像机位置（屏幕中心对应的世界坐标）
  targetX, targetY,  // 目标位置（玩家位置，但在死区内不更新）
  roomId,        // 当前房间
  transitionTimer,   // 房间切换过渡计时器
}

每帧：
1. 如果玩家切换了房间：
   - transitionTimer = 0.3
   - targetX/Y = 新房间中心
2. 如果玩家在当前房间内移动：
   - 计算玩家到 camera 中心的偏移
   - 如果偏移 > 死区阈值：更新 targetX/Y = 玩家位置（带边界 clamp）
   - 如果偏移 <= 死区阈值：targetX/Y 保持不变
3. 摄像机位置 = lerp(当前位置, target位置, easing)
4. clamp 摄像机到房间边界（保证不显示隔壁房间）

死区大小：屏幕宽度的 15-20%
easing 系数：1 - pow(0.001, dt)（帧率无关平滑）
```

## 2. 房间尺寸系统

### 问题
当前房间 8×6 格 × 36px = 288×216px，在 756px 宽屏幕上只占 38%。太小。
元气骑士的房间通常占屏幕的 70-80%。

### 实现方案
CELL 尺寸动态计算，让房间填满屏幕：
```
CELL = floor(min(viewportW / (roomW + 2), viewportH / (roomH + 2)))
```
- 普通战斗房：10×7 格 → 约占屏幕 75%
- Boss 房：14×10 格 → 约占屏幕 85%
- 单元格留有 2 格 margin（门/墙空间）

地图仍用栅格布局（GAP=1），但 CELL 按 Boss 房尺寸计算：
```
CELL = floor(min(W / 16, H / 12))  // 16 = maxRoomW+2, 12 = maxRoomH+2
// 在 756×600 屏幕上：CELL ≈ min(47, 50) ≈ 47
// 普通房 10×7×47 = 470×329 ≈ 占屏 62%
// Boss 房 14×10×47 = 658×470 ≈ 占屏 87%
```

## 3. 自动索敌系统

### Soul Knight 的索敌行为
- 近战攻击（K 键）：前方 180° 扇形范围，自动命中范围内最近的敌人
- 远程攻击（J 键）：自动锁定前方 60° 锥形范围内最近的敌人，向其发射弹道
- 显示锁定标记（敌人身上有高亮圈）

### 实现方案
```
function autoTarget(player, enemies, coneAngle) {
  let best = null, bestDist = Infinity;
  for (const e of enemies) {
    if (!e.alive) continue;
    const dx = e.x - player.x, dy = e.y - player.y;
    const dist = Math.hypot(dx, dy);
    // 检查是否在前方锥形内
    const dot = (dx * player.dir.x + dy * player.dir.y) / dist;
    const angle = Math.acos(dot);
    if (angle < coneAngle/2 && dist < bestDist) {
      best = e; bestDist = dist;
    }
  }
  return best;
}

近战（K）：coneAngle = PI（180°），范围 = 2.5 格
远程（J）：coneAngle = PI/3（60°），范围 = 无上限，发射追踪弹道
```

## 4. 其他必要系统

### 4.1 近战攻击范围
- 不是"玩家周围小圆"（太弱），而是**前方 180° 扇形**
- 打击反馈：命中时短暂 hitstop（5 帧冻结）+ 敌人击退

### 4.2 冲刺/闪避
- Shift 键：向移动方向冲刺 3 格
- 冲刺期间无敌（0.2 秒）
- CD 1.5 秒

### 4.3 敌人 AI 分级
| 类型 | 行为 |
|------|------|
| basic | 向玩家靠近，接触伤害 |
| charger | 在 6 格外加速冲刺，撞到墙眩晕 0.5s |
| shooter | 保持 5 格距离，每 2 秒发射弹道 |
| boss | 综合：近身攻击 + 远程弹幕 + 召唤小怪（HP<50%时）|

### 4.4 弹道系统
- 玩家弹道：向前方锥形自动索敌方向发射
- 敌人弹道：向玩家位置发射（预测玩家移动方向？简化：直接瞄准）
