# v5 知识点×战斗机制 详细设计（样板：物理第一章）
> 原则：每个知识点的战斗机制是量身定制的体验，不是"8种演法"的分类标签。
> 设计方法论：理解概念 → 设计交互 → 失败即教学 → 难度递进 → 融入肉鸽框架

## 设计原则
1. 体现而非告知——玩家通过交互感受概念，不需要读文字
2. 失败即教学——每次失误都展示"为什么错"，不是只扣血
3. 深度递进——同一知识点有 easy/normal/hard 三层机制变化
4. 肉鸽兼容——每个知识点=一个战斗房间+boss可能性+结算题

---

## 知识点 1：位移、速度与加速度 (phy_k1)

### 概念核心
位移≠路程。速度有方向。加速度是速度变化率。学生常混淆"走得远"与"位移大"。

### 怪物：幻影隼 (已实现 M1)
### 机制：匀变速冲刺·走位预判
玩家站在房间中。隼从远处沿 x 轴匀加速冲刺（初速 v0，加速度 a 随机）。
玩家必须在隼到达之前离开冲击区。关键是：隼的加速度越大，"看起来慢但实际上会突然变快"——
这正是学生需要培养的"加速度直觉"。

### 三层难度
| 难度 | a 值 | 视觉线索 | 教学设计 |
| easy | a=0 (匀速) | 隼以恒定速度移动 | 初学：感受"匀速"和"加速"的区别 |
| normal | a=2 (匀加速) | 隼越飞越快，身后拖尾轨迹线 | 理解：加速度让速度"积累" |
| hard | a 随机变化 | 隼忽快忽慢，需观察轨迹预判 | 进阶：瞬时加速度 vs 平均加速度 |

### 失败教学
被击中后，画面冻结 0.5s，显示隼的 v-t 曲线："你的位置：x1，隼撞击位置：x2"。
玩家看到自己站的位置 vs 轨迹交点，理解"如果加速度是 a，t 秒后位置是 ½at²"。

### 视觉呈现
- 隼身后拖尾线（位移向量）
- 速度箭头随加速变长
- 撞击瞬间爆发粒子方向 = 隼的速度方向

## 知识点 2：匀变速直线运动 (phy_k2)

### 概念核心
v=v0+at, x=v0t+½at², 2ax=v²-v0²。三个公式。学生最大困难：不知道该用哪个公式。

### 怪物：机关箭塔（新设计）
### 机制：弹道计算·站位求解
房间中有 3 座箭塔，每座显示不同的初始参数（v0, a, 发射角度）。
箭塔在 3 秒后发射。玩家必须计算出（或直觉判断）每颗弹丸的落点，站在安全区。
地面用浅色网格标注坐标，帮助玩家"算"位置。

### 三层难度
| 难度 | 参数数量 | 安全区 | 教学设计 |
| easy | 1 座塔，v0 固定 | 安全区 = 弹道不经过的连续区域 | 理解"初速决定射程" |
| normal | 2 座塔，v0/a 不同 | 需同时避开两颗弹丸 | 理解"加速度改变落点" |
| hard | 3 座塔 + 移动障碍 | 安全区极小 + 需走位 | 综合运用三个公式 |

### 失败教学
被击中后显示弹道轨迹计算（x=½at² 的具体数字代入），让玩家看到"如果我站在 x=5，t=2 时弹丸在 x=6"。

## 知识点 4：超重与失重 (phy_k4)

### 概念核心
加速度向上 → 超重（视重大于实重）；加速度向下 → 失重（视重小于实重）。
学生最难理解："超重不是重力变大，是支持力变大"。

### 怪物：重力妖（新设计）
### 机制：重力翻转·适应性走位
房间内重力每 4 秒随机变化一次——向上(a>0,超重)、向下(a<0,失重)、正常(a=0)。
玩家和怪物的移动速度、跳跃高度实时变化：
| 重力状态 | 玩家移速 | 玩家攻速 | 怪物行为 |
| 超重(g↑) | 慢 40% | 攻击伤害 +50% | 怪物体型变小、移动变快 |
| 失重(g↓) | 快 40% | 攻击伤害 -30% | 怪物漂浮、移动变慢 |
| 正常(g=) | 正常 | 正常 | 正常 |
HUD 显示当前 g 值（如 g=1.5 表示超重），玩家通过身体感受"重量变化"。

### 三层难度
| 难度 | 重力变化 | 附加条件 |
| easy | 每 5s 变一次，仅上下两态 | 无 |
| normal | 每 3s 变一次，三态循环 | 怪物也会受重力影响 |
| hard | 随机变化 + 地面有"测重板" | 踩测重板揭示当前 g 值 |

### 失败教学
被击中时显示："当前 g=1.5(超重)，你的体重×g = 实际受力"。玩家理解"重力不变，是支持力变大了"。

## 本章 Boss：运动综合兽（新设计）
### 机制：阶段转换——本章 4 个知识点的综合
| 阶段 | HP 阈值 | 机制 | 知识点 |
| P1 | 100%-60% | 匀加速冲刺+走位预判 | phy_k1/k2 |
| P2 | 60%-30% | 反震+硬抗破解 | phy_k3 |
| P3 | 30%-0% | 重力随机翻转+冲刺+反震 | phy_k4 + 综合 |

### Boss 视觉
三个阶段 Boss 外观变化——P1 像隼(高速)，P2 像犀牛(厚重)，P3 像重力妖(扭曲)。

## 实现模板：添加一个新知识点怪物
1. 在 content/subjects/physics.json 对应知识点增加字段：
   "kind": "collide|accel|oscillate|gravity|parabola|text|puzzle|..."
   "params": { "a": 2, "v0": 3, ... }  // 物理参数
2. 在 core/battle/monsters.js 增加怪物定义（moves/onImpact/phases 结构）
3. 在 core/battle/演法/<kind>.js 实现演法逻辑（如已有则跳过）
4. 跑 node 测试：独立验证怪物行为（伤害/判定/破绽）
5. 集成到 genFloor：按章节过滤知识点→生成对应怪物→房间编排
6. CDP 真机验证：完整打通一局
