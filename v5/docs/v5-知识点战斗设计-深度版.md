# v5 知识点x战斗机制 深度设计
> 物理第一章(完整样板) + 全六科创新机制 | 2026-08-25
> 核心原则：每个知识点的战斗机制是量身定制的体验，不是分类标签。

## 设计方法论
1. 体现而非告知——玩家通过交互感受概念，不需要读文字
2. 失败即教学——每次失误展示为什么错，不是只扣血
3. 深度递进——同一知识点 easy/normal/hard 三层机制变化
4. 认知根匹配——机制的思考方式=学科的认知方式
5. 修仙世界观锚点——每个机制有世界观理由(炼丹=化学、弹射=物理)

六学科核心认知挑战：
| 学科 | 认知挑战 | 游戏化方向 |
| 物理 | 理解因果链(力-运动-结果) | 即时物理模拟，玩家被推着懂 |
| 化学 | 比例守恒+物质转化 | 资源配比，失衡即爆炸 |
| 数学 | 抽象符号与空间几何脱节 | 把符号直接渲染成空间变换 |
| 地理 | 空间分布+成因推理 | 反转因果：给目标结果推分布 |
| 语文 | 语义还原(古今义差) | 语境存活，误解即死亡 |
| 英语 | 词汇构件化的陌生组合 | 词根=乐高，组合=法术 |

## 物理第一章：运动与牛顿定律 (完整样板)

### phy_k1：位移/速度/加速度 — 幻影隼(已实现)
机制：隼沿x轴匀加速冲刺。玩家观察+预判走位躲避。
三层：easy(a=0匀速)/normal(a=2匀加速)/hard(a随机变化瞬时加速)
失败教学：冻结0.5s显示v-t曲线，标注玩家位置vs撞击点

### phy_k2：匀变速直线运动 — 机关箭塔(新设计)
机制：箭塔显示(v0,a,角度)，3秒后发射。玩家算弹道落点站安全区。
三层：easy(1塔)/normal(2塔不同参数)/hard(3塔+移动障碍)
失败教学：显示弹道计算代入数字，标注 t=2时弹丸在x=6

### phy_k3：牛顿运动定律 — 反震犀牛(已实现)
机制：撞击-被弹回(感受力相互)-硬抗(借力顶住)-露破绽-出手
这是最成功的样板：完整学习弧线——被撞-感受-硬抗-理解-出手-应用

### phy_k4：超重与失重 — 重力妖(新设计)
机制：房间重力每4秒随机变化(超重g上/失重g下/正常g=)。玩家+怪物速度/伤害实时变化。
三层：easy(2态5s)/normal(3态3s)/hard(随机+测重板踩踏揭示g值)
失败教学：显示 当前g=1.5(超重)，你的视重=mgx1.5

### 物理扩展：动量守恒 — 弹射弹珠台(新设计)
机制：画弹射方向-弹珠撞击灵石矩阵(不同质量标注)-连锁碰撞-最后一颗灵石落入丹炉
核心：质量大的灵石被撞后几乎不动，小灵石飞出去——亲眼看到m大-v小
认知根：物理学本质是预测物理世界结果——mechanic让玩家预判然后验证

### 本章Boss：运动综合兽
P1(100-60%)匀加速冲刺+走位预判(phy_k1/k2)
P2(60-30%)反震+硬抗破解(phy_k3)
P3(30-0%)重力随机翻转+冲刺+反震(phy_k4+综合)

## 化学：氧化还原 — 电子传递链(新设计)
机制：多个反应池(Fe2+-Fe3+释电子,MnO4-接收电子)。拖动画线连接电子路径。连对=反应发光。
三层：L1一对一/L2多反应串/L3分叉歧化/L4竞争氧化
失败教学：短路时显示电子流动图，标注还原剂电子无处可去
认知根：化学本质是追踪粒子流动——电子是粒子，配平是流量的守衡
世界观：炼丹房。氧化还原不是你背的——是你手动传导电子修出来的

## 数学：复数运算 — 复平面法术阵(新设计)
机制：复平面(实轴+虚轴)上画符咒线迹穿过指定复数点。加法=平移、乘法=旋转+缩放。
三层：L1实数加法/L2虚数乘法(旋转90)/L3复数乘法/L4复变函数
失败教学：偏离目标时显示 画的是x(1+i)实际需要x(-1+i)差90度旋转
认知根：数学困难在符号与几何脱节——mechanic把符号直接渲染成空间变换
世界观：天机阁。在复平面上画符，乘法施咒=旋转+缩放

## 地理：热力环流 — 气温梯度造风(新设计)
机制：空白大陆轮廓。放热源冷源(标注比热容)。模拟启动-气流箭头从高压到低压形成环流。目标：在指定城市产生正确风向降水。
三层：L1单一热源/L2季风冬夏切换/L3地形干扰/L4全球三圈环流
失败教学：风向不对显示温度梯度图，标注海陆温差不够大-气压梯度力不足
认知根：地理空间因果给定分布-推结果——mechanic反转：给目标结果推分布
世界观：万象堂。布风造雨——你亲手放的热源让东海夏季吹起东南风

## 语文：文言实词 — 语境生死门(新设计)
机制：NPC说含关键实词的话(敌军走矣！)。3秒内做动作选择——慢走=死、快跑=生。NPC事后评论纠正。
三层：L1单独实词/L2连环对话/L3歧义陷阱/L4限时整段文言文
失败教学：选错NPC说 老夫曰走，乃奔跑之意，非缓步也，重播正确动作
认知根：语文实词难在语境依赖——mechanic用即刻生死后果强制语境绑定
世界观：译灵堂。古文NPC的世界里，误解一个词=死亡。走不是走路，是逃命

## 英语：词根词缀 — 词根合成塔(新设计)
机制：合成槽四周漂浮词根碎片(bio- geo- -logy -graphy un- re-)。拖拽组合入槽。正确组合=施法——bio+logy=治愈术、geo+graphy=测绘术。
三层：L1两个碎片/L2三个碎片/L3多义re-(再次/回需选对)/L4限时组合对抗敌人波次
失败教学：错误组合显示 geo+logy=地质学(非生物学)并给正确碎片建议
认知根：英语词汇难在构件化陌生组合——词根系统就是乐高，mechanic让它变成乐高
世界观：万语阁。词根法师——你拣选碎片组合成咒。un+break+able=解除封印
