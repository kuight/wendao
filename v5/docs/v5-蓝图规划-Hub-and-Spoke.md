# 《问道修仙学院》v5 · 完整开发蓝图

> 版本：v5.0 规划定稿 · 2026-08-23
> 目标对齐：**元气骑士（Soul Knight）式的"爽快 Roguelike 地牢 + 收集养成"乐趣，同时把六科知识点做成"可玩、可悟、可考"的核心机制，学习深度内嵌在玩法里，而不是做题外壳。**
> 对照原则：若一个玩法设计拿掉"学习"标签还不好玩，说明它不合格；若好玩但学不到东西，也说明设计失败。**乐趣和深度要互相成就，缺一不可。**

---

## 0. 为什么是元气骑士（参考锚点）

元气骑士好玩在哪：
1. **爽快动作**：移动+射击/近战+技能，操作反馈即时、打击感强、走位有博弈。
2. **肉鸽变数**：每局地图随机、武器/技能随机、Boss 随机，反复开一局不重样（局内成长+局外解锁）。
3. **Build 流派**：武器/羁绊/被动互相组合，形成不同打法，鼓励尝试。
4. **收集养成**：角色/武器图鉴、皮肤、局外永久升级，给长期目标。
5. **短局快节奏**：一局 10-15 分钟，死亡重开，沉没成本低。

把"元气骑士"翻译进"修仙学习"：

| 元气骑士要素 | 问道修仙 v5 对应 | 学习深度落点 |
|---|---|---|
| 地牢逐层（B1/B2/B3…） | 秘境逐层（炼气境→筑基境→金丹境…） | 每层对应一个年级段/考纲章节 |
| 随机房间+宝箱+Boss | 随机房间+顿悟/宝箱/首领房 | 房间主题=知识点 |
| 武器/技能随机掉落 | 术法/功法/法宝随机掉落 | 术法绑定知识点，用对才有效 |
| 羁绊/Build 组合 | 功法/心法/丹道 Build | 组合=跨知识点融会贯通 |
| 角色图鉴/皮肤 | 仙道道果/境界/称号 | 学习里程碑/熟练度 |
| 局外永久升级 | 道果/熟练度/功法树 | 长期成长=真掌握 |
| 一局 10-15 分钟 | 一局=一次秘境试炼 | 知识点复盘/回炉 |

**核心理念**：每只怪的"攻击机制"就是某个知识点的定律，玩家用对知识点的理解来应对 = 打怪的过程就是"用知识点打题"；打完结算答题 = "考试"；答对进下一层、答错回炉 = 学习闭环。**所以"爽"来自操作，"悟"来自机制，"考"来自结算。**

## 1. 三层分离（学习闭环的骨架，沿用已定稿范式）

| 层 | 时机 | 内容 | 让"学习"发生 |
|---|---|---|---|
| **战斗层（学）** | 进行中 | 怪招式=知识点的物理/逻辑定律，玩家实时应对 | 对抗即理解（例：牛顿第三定律怪撞你→你被弹回→要用"硬抗"破） |
| **检验层（考）** | 战后/破绽后 | 结算弹题，验证是否真懂（答题） | 答对=通关，答错=标记回炉 |
| **成长层（得）** | 结算后 | 熟练度/修为/功法/秘境推进 | 真掌握才解锁更强术法 |

**关键**：战斗层的"应对动作"必须是真实的操作博弈（走位/格挡/节奏/道具/选择），不是弹窗选答案。答题只在检验层出现。这样玩家不会把"打怪"当成"做题"，而是真正在"用知识"。

## 2. 玩什么：一局秘境（肉鸽地牢）循环

```
选择秘境/境界 → 出生在入口房间
  → 逐房间推进（随机房间类型）：
      知识房(打知识点怪) / 宝箱房(开装备术法) / 顿悟房(看讲义/跳过) / 陷阱房 / 首领房
  → 每房打完：可选"结算答题"（答对=该知识点通关+熟练度，答错=标回炉，扣一点）
  → 集齐本层知识点 → 打首领（多阶段Boss，每阶段演一个知识点）
  → 击败首领 → 进下一境界层（高一→高二→高三）
  → 死亡则本局结束，局外结算（熟练度/道果/图鉴进度保留）
```

**节奏设计**：
- 一局 10-15 分钟，房间 8-12 个，难度平滑。
- 血瓶/复活道具稀缺 → 死亡惩罚轻（保熟练度，不丢道果），鼓励反复开。
- 局内随机（地图/怪/掉宝/技能）+ 局外养成（境界/功法树/图鉴）。

## 3. 战斗怎么"爽"：演法（操作博弈 × 知识点）铺开

M1 已实现 3 种演法原型，v5 要铺到 8 种（对齐五大学科×考纲）。每种演法的**操作手感**是"爽"的来源，**机制**是"悟"的来源。

| # | 演法 | 操作博弈（爽） | 知识点（悟） | 适用学科示例 |
|---|---|---|---|---|
| 1 | **走位躲避** | 闪避冲刺、预判落点、无伤秀走位 | 匀变速/抛物线/轨迹 | 物理·运动 |
| 2 | **格挡反震** | 精准格挡、借力打力、弹反 | 牛顿第三定律/冲量 | 物理·力学 |
| 3 | **节奏抓点** | 踩节拍、看圈准时按 | 简谐振动/周期/频率 | 物理·振动波 |
| 4 | **连击combo** | 保持连击、躲避保段、操作密度 | 数列/递推/计数 | 数学·数列概率 |
| 5 | **配方应对** | 选材合成、克制、资源取舍 | 化学变化/配平/平衡 | 化学·氧化还原 |
| 6 | **时空影响** | 拖拽/开关/改变环境 | 勒夏特列/电磁感应 | 化学/物理 |
| 7 | **语义选择** | 快速读题辨义、语境推理 | 文言实词/阅读 | 语文/英语 |
| 8 | **多阶段BOSS** | 组合上述多种，读阶段切换策略 | 综合跨章 | 章节综合 |

> 每种演法都要能**独立好玩**（操作反馈爽），同时**必靠对应知识点**（不悟则被机制惩罚）。这是 M2 的核心攻坚。

## 4. 装备/Build：把"掌握"变成"变强"

**玩家变强 = 更会用知识 + 更强的术法装备。** 两者绑定，让"学习"直接转化为"战力"。

- **术法（主动技能）**：随机掉落，绑定知识点。例：掌握牛顿第三定律→【反震·借力打力】可弹反物理怪。
- **功法（被动Build）**：跨知识点组合出流派。例：掌握"匀变速+抛物线"→【轨迹预判】大幅提升走位演法的躲闪判定窗口。
- **心法/丹道（辅助）**：恢复、护盾、属性加成（调数值平衡）。
- **图鉴**：收集怪物图鉴（每只怪=一个知识点的可视化）+ 术法图鉴 + 秘境图鉴，点亮即成就感+局外属性。

**Build 设计要点**：不同演法有不同优解 Build，鼓励"练熟某演法"→"出对应流派"，形成成长正反馈。切忌做成无脑堆数值——Build 的价值=让你"更能用知识"。

## 5. 世界观/叙事（轻量，托住爽感）

不写长文本。用"秘境+境界+道果"做轻世界观：
- 六科=六条仙途（雷霆殿·物理 / 丹鼎峰·化学 / 山河阁·地理 / 推衍宫·数学 / 文渊阁·语文 / 译灵堂·英语）。
- 境界递进=年级段（炼气=高一 → 筑基=高二 → 金丹=高三）。
- Boss=章末大妖，有名字/台词/机制，打完给道果（=该章毕业证明）。
- 教程内嵌在"顿悟房"（用云端 tutorials 的 .md 讲义做卡片），看一次=获得该知识点机制提示。

## 9. 风险与平衡（提前标注，避免返工）

1. **演法=知识点 的映射强度**：太直白=做题；太隐晦=学不到。需"先让玩家用知识得利"（正反馈），再"不用知识被惩罚"（负反馈），形成"懂了才爽"。
2. **数值平衡**：Roguelike 的随机掉宝与 Build 数值极易失衡。**涉及战斗数值调整前必须停下问你**（授权边界）。
3. **一局时长**：别做成 40 分钟长局，违背"短局快节奏"。锚定 10-15 分钟。
4. **答题与战斗的割裂感**：结算答题不能变成"打断爽感"的弹窗地狱。做成"顿悟/验心"小环节，答对给爽快奖励特效，答错快速回炉不拖沓。
5. **存档兼容**：破坏性改存档 schema 前先问 + 先备份 + 打 tag（规范第 2 条）。
