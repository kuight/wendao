## 0. 核心范式：战斗 = 体验知识点

**根本转变**：v0.4 及之前，战斗都在"答题"——把题目嵌进游戏外壳。这是"游戏化刷题"。

v0.5 的范式：**战斗让玩家"体验"知识点本身。** 就像《相对论游戏》里你移动时世界真的时间膨胀——**怪物/敌人的攻击机制，就是某个知识点的物理或逻辑定律。** 玩家对抗怪物，不是答题，而是在"感受"和"运用"这个知识点。打完，再用题检验是否真懂。

**三层分离（你的模型）**：
| 层 | 内容 | 时机 | 耦合 |
|---|---|---|---|
| 战斗层（学） | 对抗"知识点怪物"，它的招式=知识点的定律/现象，玩家在对抗中体验并运用它 | 进行中 | 战斗=体验知识 |
| 检验层（考） | 战斗胜利后进入结算，用题验证是否真懂（答对=通关，答错=标记回炉重学） | 战后 | 检验在此 |
| 成长层（得） | 体验+检验都过 → 熟练度/修为/掉落/关卡推进 | 结算后 | 学习闭环 |

## 1. 战斗演知识的机制设计（核心难点破题）

**命门问题**：战斗怎么让玩家"体验"知识点，而不是"答题"？

**答案（从案例提炼）**：**怪物的"招式机制" = 知识点的"定律/现象"。** 玩家必须用对该知识点的理解来应对，而应对的过程本身就是理解的过程。

### 原则：怪物的每一种攻击行为 = 该知识点的一种"物理/逻辑呈现"

| 知识点 | 怪物的招式机制（战斗演知识） | 玩家应对 = 运用知识点 |
|---|---|---|
| 牛顿第三定律 | 怪撞你→你被弹回"力相互"；怪不硬拼而"反震"你的攻击 | 你看懂"力是相互的"，改用"不动硬抗"或"借力"破它 |
| 简谐振动(回复力) | 怪沿"弹簧式"往复扑，振幅越大越猛、频率越快越难躲 | 你抓它的"回复力周期"，在平衡点出手破防 |
| 氧化还原 | 怪带"电子转移"冲锋，碰你你会被"氧化腐蚀" | 你用"还原剂"护身道具，克制它的氧化攻击 |
| 函数单调性 | 怪沿"单调增减"轨迹追，递增区越跑越快、递减区会顿 | 你利用它的"单调性变化点"拉开距离/近身 |
| 匀变速运动 | 怪做"匀加速/匀减速"冲刺，初速末速有规律 | 你算它的"位移/时间"预判落点躲避 |
| 化学平衡 | 怪被"勒夏特列"约束，你施加压力它往一边移 | 你"加压/降温"推动平衡，削弱它 |
| 电磁感应 | 怪冲来带"感应电流"，磁场变化时它变强 | 你"改变相对运动/磁场"让感应减弱 |
| 文言实词 | 怪吟出"一词多义"，不同上下文含义不同 | 你根据语境"选对义"来破它的招 |

### 战斗流程（通用骨架，每怪按知识点特化）

```
遇怪 → 怪物进入"演知识模式"
  ├─ 怪物用招式A呈现该知识点的一个定律/现象（玩家观察、理解）
  ├─ 怪物用招式B考验运用（玩家需用理解来应对）
  └─ 玩家应对成功 → 破绽 → 玩家施法（该科修为×理解度）→ 怪掉血
      应对失败 → 受击（护盾/修为扣减）+ 该知识点标"未悟"
```

**关键**：玩家"应对"的动作，就是"运用知识点"的动作。没有弹窗答题，只有真实的对抗。**对抗即理解。**

## 2. 结算层：战斗后的检验（做题在此发生）

战斗胜利 → 进入"结算/检验"——**此时才用题验证**。

- **结算玩法**：播放"顿悟/验心"小环节，弹出**该知识点的 1-3 道题**（`knowledge.getQuestion`）
- **答对** → 熟练度大幅+、该科修为+、通关，得掉落，推进关卡
- **答错** → 标记"回炉"，熟练度回退，需再打这只知识点怪物重悟，再验
- **连对** → combo 加成

**这样"学"（战斗）和"考"（结算）彻底分离又环环相扣**：打怪是理解，答题是确认，理解不透就回炉重打。

---

## 3. 成长层：学习闭环

- **熟练度** = 对该知识点的掌握度（战斗胜利+、结算答对+、答错-）
- **修为** = 六科修炼值（灵力/丹力/算力/舆力/文力/语力），战斗胜利+该科修为
- **功法** = 掌握知识点解锁，效果绑定知识点逻辑（例：掌握牛顿第三定律→「作用反作用·反震」对会"反震"的怪伤害翻倍）
- **关卡** = 章节/秘境推进，靠"通关该章所有知识点的怪+验"驱动

---

## 4. 关卡结构（肉鸽地牢 + 题型编排保留）

沿用 v0.4 的"秘境-小关-房间"，但房间的核心不再是"题型"，而是**"知识点主题"**：
- 每房间 = 一个/一组知识点怪（不是题型）
- 房间类型：初始房/知识点房/宝箱房/顿悟房/传送门房/首领房
- 难度阶梯对齐考纲（高一入门→高三冲刺），怪的招式复杂度递增
- 首领房 = 该章综合知识点 BOSS，多阶段，每阶段演一个知识点

## 5. 多战斗形式（保留 v0.4 的八种模式，作为"演知识"的载体）

"演知识"不排斥多样操作。不同知识点的"现象"用不同操作最直观：

| 知识点的现象 | 最适合的战斗形式 | 例 |
|---|---|---|
| 运动/力/轨迹 | 走位躲避 | 匀变速怪冲撞 |
| 周期性/回复力 | 节奏抓时机 | 简谐振动怪 |
| 守恒/相互 | 格挡反震 | 牛顿第三定律怪 |
| 化学变化/配平 | 道具应对 | 氧化还原怪 |
| 平衡/勒夏特列 | 施加影响 | 化学平衡怪 |
| 多义/语境 | 选择应对 | 文言实词怪 |
| 综合/压轴 | 多阶段BOSS | 章末首领 |

**但核心不变**：无论用哪种操作，**玩家的应对动作 = 运用知识点，不是做题。**

## 8. M1 原型验收（锋利最小验证）

打一只"牛顿第三定律怪"：它撞你→你被弹回（演"力相互"），你看懂改用"硬抗"→破绽出现→施法击败→进结算→答"为什么撞你会被弹回"的题→答对=通关+熟练度。**玩家打完这一个怪，能自己说出"作用力和反作用力是相互的"——因为他亲手感受到了。**
