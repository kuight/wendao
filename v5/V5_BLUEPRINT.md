# 《问道修仙学院》v5 开放世界蓝图（draft v0.1）

> 状态：草稿，等待参考游戏调研结果合并
> 作者：本地 agent · 2026-08-21

## 0. 愿景与目标

从 v4.4.0 的「文字感、AI 味重、枯燥」的刷题界面，升级为「大型开放世界感」的二次元修仙学习游戏。

核心转变：
- **从界面到世界**：不再是一页页文字题卡，而是一个可探索的修仙世界（门派/洞府/秘境/城镇/副本），学习行为内嵌于世界探索。
- **从题海到体验**：刷题不再独立存在，而是「探索 → 遇敌 → 战斗 → 答题」的循环里的一环，答对答错有即时反馈。
- **从单机到沉浸**：世界地图、角色动画、场景切换、音效、粒子特效、打击反馈构成沉浸感。

## 1. 三大支柱

| 支柱 | 现状 v4 | 目标 v5 |
|---|---|---|
| 世界 | 静态文字列表 + 大地图入口 | 可漫游的 2D 等距/俯视世界，NPC、场景切换、昼夜 |
| 战斗 | 文字回合制问答 | 视觉化战斗 + 答题驱动技能、打击反馈、combo |
| 学习 | 扁平题卡 | 分学科×章节×难度的知识图谱，答题即修行 |

## 3. 世界呈现方案（调研后定稿）

**方案：2D 等距/俯视混合 + 多层视差背景。** 用最少素材达成开放世界纵深感。
- 地图：程序化生成区块网格（SVG/Canvas 绘制），角色自由移动
- 背景：CSS 3D 多层视差（`transform: translate3d` 不同速率），纵深+大气氛围
- 场景切换：`clip-path` 扇形/推拉转场，避免生硬跳变

## 3.5 视觉/交互精美度层（调研后定稿——v5 脱胎换骨的关键）

以「音游反馈 + 玻璃拟态 + 桌游材质」三合一，全部纯 CSS/轻 Canvas：

| 优先级 | 手法 | 用途 | 技术栈 | 成本 |
|---|---|---|---|---|
| P1 | 音游式答对/答错反馈 | hit stop+判定环+粒子+闪白+震动 | CSS/Canvas | 低 |
| P2 | 玻璃拟态+深色渐变 HUD | backdrop-filter 浮层替代纯文字面板 | CSS | 中 |
| P3 | 物理缓动曲线统一 | 全动画 cubic-bezier 去线性飘 | CSS | 低 |
| P4 | 卡片/令牌/道具材质 | 圆角+双层阴影+渐变受光 | CSS | 低 |
| P5 | 地图视差分层背景 | CSS 3D 多层移动 | CSS | 低 |
| P6 | combo 连击系统 | 答对连击计数+光效/音高递增 | CSS/WebAudio | 低 |
| P7 | 粒子光效(灵气/突破) | Canvas 粒子做升级仪式感 | Canvas | 中 |
| P8 | 飘字飘分(顿悟/圆融) | 判定等级彩色飘字 | CSS | 低 |
| P9 | 网格噪点纹理 | SVG data-URI 叠加去塑料感 | CSS/SVG | 低 |
| P10 | 转场动画 | clip-path 扇形/推拉 | CSS | 低 |

## 4. 学习融合设计（核心差异点）

### 4.1 三层知识模型
- 学科（6 科）→ 章节（每科 6-8 章，对齐教材）→ 知识点（每个知识点 1-N 题）
- 现有题库已有 `difficulty` 字段（easy/medium/hard），但缺少「年级 / 章节」维度 → v5 需为每题补 `grade`(高一/高二/高三) 与 `chapter` 标签

### 4.2 答题即修行
- 答对：积累熟练度，推进境界/突破；答错：触发「顿悟」回炉重学该知识点
- 连击 + combo：连续答对触发暴击/连招视觉反馈（融合音游打击感）

### 4.3 进度闭环
- 章节通关 = 解锁新地图区域 / 剧情 → 形成"学习进度 = 世界进度"的开放世界驱动

### 4.4 数据模型（题库条目目标 schema）
```js
{
  id: 'phyq0001',
  manualId: 'phy_m1',
  type: 'single',
  difficulty: 'easy',   // 既有
  grade: '10',          // 新增：高一/高二/高三
  chapter: '振动与波',  // 新增：章节
  q, answer, explain, options
}
```
