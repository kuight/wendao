# 存档格式说明

存档文件本质是一个 JSON 文本，存放在游戏运行时由前端导出/导入。

## 字段列表

| 字段 | 类型 | 说明 |
|---|---|---|
| `角色名` | string | 玩家自定义身份 |
| `称号` | string | 修仙者称号，如 "炼气一层弟子" |
| `境界` | string / int | 当前境界（炼气一层、筑基中期、金丹圆满 等） |
| `经验` | int | 当前境界下的累积经验 |
| `灵石` | int | 可消耗的虚拟货币 |
| `修为` | int | 学术/解题综合进度 |
| `道心` | int | 心态指标，过低会触发反噬 |
| `已斩妖` | int | 已完成的题目数 |
| `道途` | array | 主线学科进度，如 `["物理·选必", "化学·选必", "地理·选必"]` |
| `存档时间` | ISO string | 写入时间 |
| `版本` | string | 生成此存档的游戏版本号 |

## 样本存档

见 `../data/样本存档/sample-save.json`。

## 兼容性策略

- 旧版本字段在读取时被忽略，不报错。
- 新字段写入后向前兼容（旧版本读取直接忽略未识别字段）。
- 主版本号升级（如 v4.3 → v4.4）时建议重置存档。
