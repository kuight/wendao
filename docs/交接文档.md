# 交接文档（占位）

> ⚠️ 占位文件。仓库原 `交接文档.txt` 尚未上传，上传后将整体覆盖本文件。

本文件由 GitHub 仓库框架初始化时自动生成，作为上轮开发交接说明的占位。

## 框架约定

- 所有开发记忆的 .txt 已统一转写为 .md，放到 `docs/`。
- 历史归档 zip 放到 `archive/备份/`。
- 当前主版本源代码放到 `src/项目/`。
- HTML 预览页放到 `src/preview/`。
- 游戏存档样本放到 `data/样本存档/`。

## 等你补齐的内容

1. `docs/交接文档.md` ← 替换为原 `交接文档.txt` 内容（UTF-8）
2. `docs/开发记忆-主.md` ← 替换为原 `记忆.txt` 内容
3. `docs/开发记忆-副本.md` ← 替换为原 `记忆 - 副本.txt` 内容
4. `docs/开发记忆-新.md` ← 替换为原 `新记忆.txt` 内容
5. `data/样本存档/sample-save.json` ← 替换为原 `存档.txt` 内容（如果 .txt 已经是合法 JSON）
6. `src/preview/*.html`
7. `src/项目/*.js`（当前主版本题库/手册）
8. `archive/备份/*`（历史版本与备份的全部 zip、js、css）
