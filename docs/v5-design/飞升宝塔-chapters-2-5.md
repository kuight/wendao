**Boss：九霄雷尊**
- 传说：上古雷劫化灵，执掌九重天雷。凡渡劫者必经其考验，雷尊只认可"以正心御雷"的修士。
- 机制：每 3 回合释放「九霄雷狱」（全体敌人数+1）；答错被雷劈（HP-15%）。
- 击败奖励：灵宠蛋碎片×5、称号「御雷者」、解锁第 3 章。
