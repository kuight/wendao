## 2. 本批次已交付原型（3 个）

### 2.1 灵笔绘卷（#08 变体）— `src/v5/minigame/drawing-puzzle/`

- **玩法**：canvas 自由手绘临摹参考 SVG（灵符/灵草/法器），笔迹越近评分越高。
- **难度门槛**：easy=筑基（3 笔）、mid=金丹（6 笔）、hard=飞升（10 笔），按 realmId 解锁。
- **评分**：笔迹点与参考笔画簇的最近距离 → 准确率 0–100%；叠加完成用时。
- **存档**：`state.v5.minigame.drawing.matches`。
- **文件**：`index.html` / `drawing-core.js` / `灵符-ref.js` / `灵草-ref.js` / `法器-ref.js`（参考 SVG 以 base64 内联，零网络依赖）。

### 2.2 宗门堂（#07 变体）— `src/v5/minigame/tycoon-tower/`

- **玩法**：俯视 2D 宗门塔，楼层随境界解锁（realmId 门槛 0/3/6/9/12），灵石自动产出。
- **三类升级**：弟子等级（+灵宠捕获率）、灵脉纯度（+被动产出）、丹药品级（+稀有掉落率）。
- **斩断红尘**：重置囤积与等级，换取永久灵宠加成（捕获 +1%/点、稀有 +0.4%/点）。
- **存档**：`state.v5.minigame.tycoon`（对 `wendao_save_v2` 纯增量）。
- **文件**：`index.html` / `tycoon-core.js`。

### 2.3 桃花仙（#10 变体）— `src/v5/minigame/ai-tutor/`

- **玩法**：聊天气泡 UI + 二次元吉祥物「桃花仙」，输入知识点/题目 → 分步讲解。
- **引擎**：确定性规则匹配（**无真实 AI API**），6 学科 × 30 模板 = 180 条 curated Q&A。
- **模板字段**：`detect_regexp` / `scaffold_steps[]` / `final_formula` / `example`。
- **题库挂载**：读取 `src/data/v5-expansion/*-bank-v5.json`（本批次为 8 题存根）。
- **文件**：`index.html` / `tutor-core.js`。

## 3. 教育映射原则

- 每个知识点（6 学科 × 7 分支 × ≥5 考点 = 210）须有 ≥3 种玩法可练（E06）。
- 难度 1–5★ 对应高一→高考冲刺梯度。
- 错题自动进入对应玩法（错题→卡组/炼丹/复习调度）。

## 4. 技术约束

- 全部零后端、零 CDN 依赖，解压本地 HTTP 即可玩。
- 立绘/字体/谱面 100% 合法可商用（CC0/自制/思源 OFL）。
- 存档全部走 `GameV5.save.writeV3`，命名空间增量，不破坏 v2/v3 既有键。
