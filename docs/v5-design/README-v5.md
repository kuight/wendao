## 1. 一句话定位

把《问道修仙学院》从"文字感、AI 味、枯燥"的伪开放游戏，重做成"真正能装进口袋的大世界修仙学院"：走格、抽卡、音游、卡组、Roguelite、炼丹养灵宠，同时把 6 门学科的考点矩阵以"练习+错题+复习"闭环长进脑子里。

## 2. 目标用户

| 用户 | 场景 | 设计诉求 |
|---|---|---|
| 高一→高三学生 | 课间/通勤碎片时间 | 单局 ≤3 分钟闭环，随时可停 |
| 高考冲刺生 | 考前 3 个月 | 高频考点+真题梯度 1–5★，错题自动复习 |
| 教师/家长 | 查看学习数据 | 本地 JSON 导出（v5.1 起），不上云 |

## 4. 内容管线规则

### 4.1 题库生产

- 目标：≥6300 题（v4 已有 ~4173 题作种子，走 `v4_bank_to_v5.js` 转换）。
- 来源配比：自产 50% + 政府开放平台 30%（国家中小学智慧教育平台等，标注 CC BY）+ 历史真题 20%。
- 每题 JSON 遵循 v5 schema（`id/v/subject/branch/points/difficulty/type/stem/options/answer/sourceTags/relatedPoints/estimatedSec/mediaRef/version`）。
- 反重复：Jaccard ≥0.85 / Levenshtein 触发"疑似重复"标记人工核。

### 4.2 小游戏接入

- 每个知识点须 ≥3 种玩法可练（E06 验收）。
- 小游戏统一放 `src/v5/minigame/<name>/`，含 `index.html` + `<name>-core.js`。
- 存档命名空间增量写入 `state.v5.minigame.<name>`，禁止改既有键。

### 4.3 命名约定

| 项 | 约定 | 示例 |
|---|---|---|
| 小游戏目录 | `src/v5/minigame/<kebab-name>/` | `drawing-puzzle/` |
| 核心模块 | `<kebab-name>-core.js` | `tycoon-core.js` |
| 参考资源模块 | `<主题>-ref.js` | `灵符-ref.js` |
| 题库文件 | `src/data/v5-expansion/<subject>-bank-v5.json` | `physics-bank-v5.json` |
| 文档 | `docs/v5-design/*.md`（不进 src，避免 MANIFEST 膨胀） | `save-schema-v5.md` |
| 存档命名空间 | `state.v5.minigame.<name>` | `state.v5.minigame.drawing` |
